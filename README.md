## 👩‍💻 About

A personal developer portfolio built to stand out — editorial design with electric lime accents, bold typography, and smooth animations. Showcases my projects, skills, and background as a Java Full Stack Developer.

---

## ✨ Features

- 🎨 **Unique editorial design** — electric lime `#C8FF00` accent color, Bebas Neue typography, film grain overlay
- 🖱️ **Custom cursor** — glowing lime dot with a smooth trailing ring
- 📸 **Offset photo frame** — stylized CSS border effect on profile photo
- ⌨️ **Typing animation** — cycles between "Developer" and "Engineer"
- 📜 **Scrolling marquee** — animated skills ticker strip
- 🎬 **Scroll reveal animations** — sections fade in as you scroll
- 🎛️ **Project filter** — filter projects by category
- 📱 **Fully responsive** — works beautifully on mobile, tablet, and desktop
- ⚡ **Fast & optimized** — built with Vite for instant loading

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| ⚛️ **React 18** | Building UI components |
| ⚡ **Vite** | Fast build tool and dev server |
| 🎨 **Tailwind CSS** | Responsive layout and utility classes |
| 🎭 **CSS Variables** | Design token system for colors and themes |
| 🔤 **Google Fonts** | Bebas Neue · Outfit · JetBrains Mono |
| 👁️ **IntersectionObserver API** | Scroll-triggered reveal animations |
| 🔗 **React Hooks** | useState · useEffect · useRef |
| 🌐 **Vercel** | Hosting and auto-deployment |
